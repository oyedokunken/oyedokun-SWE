  AUTHENTICATION FLOWS
  ----------------------
  Email/Password:
    POST /register -> OTP email -> POST /verify-email -> JWT issued
    POST /login -> compare bcrypt -> JWT + refresh token

  Google OAuth 2.0:
    GET /google-redirect -> accounts.google.com
    -> GET /google-callback?code= -> exchange code -> userinfo
    -> upsert user -> JWT + redirect to /auth-callback

  Token Refresh:
    Axios 401 interceptor -> POST /auth/refresh -> new access token
    Automatic, transparent to all callers

Overview
Higher education demands students manage multiple concurrent obligations — coursework, assignments, group projects, and examinations — simultaneously. Poor academic task organisation leads to missed deadlines, heightened stress, anxiety, and a measurable decline in student mental health.

EduPilot addresses this gap by developing a student-friendly workflow management system that applies Critical Path Method (CPM) to automate scheduling, identify task dependencies, and surface the exact sequence in which academic work should be completed. It integrates a mental health monitoring module to track cognitive load in real-time alongside the scheduling engine.

Features
Academic Task Management
Task Creation & Organization: Create, categorize, and prioritize academic tasks
Dependency Management: Define task dependencies and prerequisites
Deadline Tracking: Automated deadline reminders and progress monitoring
Progress Visualization: Interactive Gantt charts and timeline views
Critical Path Method (CPM)
Automated Scheduling: CPM algorithm calculates optimal task sequences
Critical Path Identification: Highlights tasks that directly impact project completion
Float Calculation: Shows flexibility in non-critical task scheduling
What-if Analysis: Simulate impact of task delays on overall timeline
Mental Health Monitoring
Stress Index Calculation: Real-time cognitive load assessment
Wellness Nudges: Proactive recommendations for breaks and stress management
Workload Analytics: Visual representations of academic burden over time
Schedule Adherence Tracking: Monitor compliance with recommended schedules
User Experience
Modern UI/UX: Clean, intuitive interface built with Next.js and Tailwind CSS
Responsive Design: Optimized for desktop, tablet, and mobile devices
Dark Mode Support: Reduce eye strain during extended study sessions
Real-time Updates: Live synchronization across devices
